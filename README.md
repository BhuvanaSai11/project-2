# Sankalp 2026 - T1-Core Platform

An open-source, self-hostable hackathon submission and judging platform built for the Sankalp 2026 hackathon.

## Event Track
**Track A - Students Track**

This platform supports student project submissions, team formation, and judging for the Sankalp hackathon.

## Features (T1-Core)
* **Authentication & Sessions:** Secure role-based access for Participants, Judges, Organizers, and Admins.
* **Event Creation & Configuration:** Set up events, tracks, prizes, and submission deadlines.
* **Team Formation:** Seamless team creation via unique invite links.
* **Project Submission:** Draft, edit, and finalize submissions before the deadline.
* **Public Gallery:** Searchable public view of submitted projects.

## Quick Start (Local Deployment)
The platform runs locally with a single command via Docker:

1. Clone this repository:
   ```bash
   git clone https://github.com/BhuvanaSai11/project-2.git
   cd project-2
   ```

2. Start the app with Docker Compose:
   ```bash
   docker compose up
   ```

3. Open the app in your browser at:
   ```text
   http://localhost:3000
   ```
